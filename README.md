# Global FDI Analysis & Reporting 📊

[![Power BI](https://img.shields.io/badge/Report-Power_BI-yellow?logo=powerbi)](https://powerbi.microsoft.com/)
[![PDF Report](https://img.shields.io/badge/Download-PDF_Report-red?logo=adobe-acrobat-reader)](FDI%20Analytics%20Report.pdf)

This repository contains a comprehensive **Foreign Direct Investment (FDI)** analytics suite, featuring an advanced Power BI dashboard and a detailed analytical report. 

![FDI Dashboard Preview](fdi_dashboard_preview.png)

## 📁 Project Contents

-   **[FDI Analysis.pbix](FDI%20Analysis.pbix):** The core Power BI project containing interactive data models, DAX measures, and high-end visualizations.
-   **[FDI Analytics Report.pdf](FDI%20Analytics%20Report.pdf):** A professional PDF summary of key investment insights and strategic recommendations.
-   **[FDI Analysis.xlsx](FDI%20Analysis.xlsx):** The underlying dataset used for the analysis.

## ✨ Analytics Highlights

-   **Interactive KPI Monitoring:** Real-time visibility into Total FDI Inflows, Year-over-Year Growth, and Market Stability.
-   **Multi-Dimensional Analysis:** Breakdowns by **Sector** (Tech, Manufacturing, Energy) and **Geographic Region**.
-   **Trend Forecasting:** Historical data analysis with visual projections for future investment cycles.
-   **Power BI Visuals:** Custom-designed charts with professional color palettes and intuitive drill-down capabilities.

## � How to Use

### 1. Interactive Dashboard (Power BI)
To experience the full interactive dashboard:

3.  Interact with filters to drill down into specific regions or timeframes.

### 2. Analytical Report (PDF)
For a static, executive summary:
1.  Open [FDI Analytics Report.pdf](FDI%20Analytics%20Report.pdf) directly in your browser or any PDF reader.
